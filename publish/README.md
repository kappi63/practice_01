# 建築鋼材表 検索アプリ

JIS規格の形鋼・鋼管の断面性能と材料規格を検索できる単一HTMLアプリです。

**公開URL → https://fkol-apps.github.io/steel-materials-app/**

## 機能

- **対応鋼材**: H形鋼 / 角形鋼管 / 円形鋼管 / 溝形鋼 / 等辺山形鋼 / 材料規格(SS400・SN・SM・BCR等)
- **検索**: キーワード検索(例: `H-300`、`200×200`、`SS400`)。全角/半角・×/x の表記ゆれを自動吸収
- **ソート**: 列見出しクリックで並べ替え
- **重量計算**: 行クリックで詳細表示と重量計算(長さ×本数 → kg/t)
- スマホ対応・ダークモード対応

## 使い方

ブラウザで `index.html` を開くだけで動作します(インストール・サーバー不要)。

## 注意

数値は JIS G 3192 / G 3466 / G 3444 等およびメーカーカタログに基づく参考値です。
設計に使用する際は必ず最新のJIS規格・カタログ・告示で確認してください。

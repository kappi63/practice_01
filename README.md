## 建築鋼材表 検索アプリ

`index.html` をブラウザで開くと、建築鋼材の規格表を検索できます。

- **対応鋼材**: H形鋼 / 角形鋼管 / 円形鋼管 / 溝形鋼 / 等辺山形鋼 / 材料規格(SS400・SN・SM・BCR等)
- **機能**: キーワード検索(例: `H-300`、`200×200`、`SS400`)、列クリックでソート、行クリックで詳細表示と重量計算(長さ×本数)
- インストール不要の単一HTMLファイルです。ダブルクリックで開くだけで動作します。

※ 数値はJIS規格・メーカーカタログに基づく参考値です。設計時は必ず最新の規格・カタログで確認してください。
